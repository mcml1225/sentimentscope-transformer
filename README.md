# SentimentScope: Sentiment Analysis with Transformers

Final project for the Udacity **AWS AI Programmer** course: a transformer model built **from scratch in PyTorch** that classifies IMDB movie reviews as **positive** or **negative**.

> Scenario: as a Machine Learning Engineer at *Cinescope*, an entertainment company, the goal is to understand user sentiment from movie reviews to improve the recommendation system.

## Project goals

- Load, explore and prepare a text dataset for training a transformer with PyTorch.
- Adapt a GPT-style transformer architecture (`DemoGPT`) for binary classification.
- Train and evaluate the model on IMDB, reaching **more than 75% test accuracy**.

## Dataset

[IMDB Large Movie Review Dataset](https://ai.stanford.edu/~amaas/data/sentiment/) (Maas et al., 2011): 50,000 reviews, balanced between positive and negative.

| Split | Positive | Negative | Total |
|-------|---------:|---------:|------:|
| Train | 12,500 | 12,500 | 25,000 |
| Test  | 12,500 | 12,500 | 25,000 |

The training set is shuffled and split 90/10 into **train (22,500)** and **validation (2,500)**.

In the Udacity workspace the dataset came as `aclImdb_v1.tar.gz`. To run the project locally, the same data is downloaded from Hugging Face ([`stanfordnlp/imdb`](https://huggingface.co/datasets/stanfordnlp/imdb)) and written to disk in the original `aclImdb/{train,test}/{pos,neg}/*.txt` layout, so the rest of the notebook works unchanged.

## Model

| Component | Details |
|-----------|---------|
| Tokenizer | `bert-base-uncased` (subword tokenization, vocab ≈ 30,522) |
| Max sequence length | 128 tokens |
| Embeddings | Token + learned positional embeddings |
| Transformer blocks | Pre-LayerNorm blocks with multi-head self-attention + feed-forward (GELU) |
| Classification head | Mean pooling over the sequence → `Linear(d_embed, 2)` |
| Loss / optimizer | Cross-entropy / AdamW (lr = 3e-4) |
| Batch size | 32 |

Baseline configuration: `d_embed=128`, `layers_num=4`, `heads_num=4`, `head_size=32`, `dropout_rate=0.1`.

## Results

| Experiment       | d_embed | Layers | Epochs | Best Val. Acc. | Final Val. Acc. | Test Acc. |
|------------------|--------:|-------:|-------:|---------------:|----------------:|----------:|
| Baseline         | 128 | 4 | 3 | 77.96% | 77.96% | **76.56%** |
| More epochs      | 128 | 4 | 5 | 78.04% | 78.04% | 76.68% |
| Even more epochs | 128 | 4 | 8 | 80.04% | 78.80% | 77.10% |
| Larger model     | 256 | 6 | 5 | 79.76% | 79.28% | **77.13%** |

All configurations exceed the 75% test accuracy target. Longer training and a larger model improve accuracy, but with diminishing returns (+0.57 pp from baseline to the larger model).

### Key takeaways

- A decoder-style transformer can be adapted for classification by pooling token representations into a single vector and adding a linear classification head.
- Subword tokenization handles a large vocabulary efficiently.
- Shuffling, train/validation splitting and batching matter for model performance.
- The validation set monitors training; the test set gives an unbiased final evaluation.

### Beyond the requirements

- Model checkpoint saved with `torch.save`.
- `SentimentPredictor` class for inference on new, raw reviews.
- Additional experiments with more epochs and a larger architecture.

## How to run

```bash
# 1. Clone the repository
git clone https://github.com/<your-username>/sentimentscope-transformer.git
cd sentimentscope-transformer

# 2. Create and activate a virtual environment
python -m venv .venv
.venv\Scripts\activate          # Windows
# source .venv/bin/activate     # macOS / Linux

# 3. Install dependencies
pip install -r requirements.txt

# 4. Open the notebook
jupyter notebook SentimentScope_starter.ipynb
```

The notebook downloads the dataset itself. You can also prepare it beforehand with `python scripts/download_data.py`.

A GPU is recommended: training on CPU works but takes considerably longer.
